# Agent Teams セットアップ手順

## Step 1: 有効化

```bash
# settings.json
{
  "CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS": true
}
```

## Step 2: CLAUDE.md

プロジェクトルートの `CLAUDE.md` に全エージェントの役割定義・ガバナンス・Safety Checksを記載済み。

## Step 3: フルチーム起動

```bash
claude --model opus
```

### 起動プロンプト

```
あなたはBTC Research Corp.の社長です。以下の9人チームをフル編成してください。

【経営陣・監視機関】
1. 株主（大起の代理人）: 社長の全判断をレビューし、鉄のルール遵守を監視
2. 倫理委員会: 全社の意思決定を独立監査。認知バイアスチェックを実施

【事業部門】
3. CFO: 資本金3万円のデモ運用リスク管理ルールを策定
4. CTO: bot_ver3のSPECIFICATION.mdをレビューし、安全装置の設計
5. エンジニア: DEMO_MODEの紙取引シミュレーター実装
6. デバッガー: 既存コードの安全装置チェック（レバレッジ混入なし確認）
7. 戦略企画: 3万円現物に最適な戦略を3つリサーチ
8. 顧客（タナカさん）: 現時点のREADMEとBot設計を初心者目線で評価

【実行ルール】
- 全員並列で作業し、完了後に社長に報告
- 社長は全報告を統合し、方針を決定
- その後、株主が社長の判断をレビュー
- 倫理委員会が全プロセスを監査し、バイアスや違反がないか確認
- 鉄のルール（デモモード・現物のみ・レバ禁止）を全員に徹底すること
```
